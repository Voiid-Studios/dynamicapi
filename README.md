# DynamicAPI Wiki (DWiki)

Welcome to the `wiki` branch of DynamicAPI!

This branch holds the source files for the [DynamicAPI Wiki][wiki], built with [MkDocs Material][mkdocs-material] and deployed automatically to GitHub Pages on every push.

---

## Previewing locally

To preview the wiki on your machine, make sure you have Python 3.10 or later installed, then run:

```sh
pip install mkdocs-material
```

Once installed, navigate to the root of this branch (where `mkdocs.yml` is located) and run:

```sh
mkdocs serve
```

This starts a live preview at `http://127.0.0.1:8000` that automatically refreshes whenever you save a file.
